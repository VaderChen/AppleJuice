# Get help with AppleJuice

Start with the [installation guide](docs/product/install.md) and the [tested game list](https://vaderchen.github.io/AppleJuice/tested/?lang=en). Match the game edition and check whether its rating requires upscaling or interpolation.

Search [existing issues](https://github.com/VaderChen/AppleJuice/issues) for the same build and symptom. If you can reproduce it, [choose a report type](https://github.com/VaderChen/AppleJuice/issues/new/choose). Include the shortest sequence that reaches the problem. Remove account names, tokens, license keys, save files and personal paths from logs or screenshots. For sensitive findings follow the [security policy](SECURITY.md).
