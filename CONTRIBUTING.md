# Contributing

A useful first contribution is a test result for a specific game edition and release. Use the [game report](https://github.com/VaderChen/AppleJuice/issues/new?template=game.md) and describe a scene another player can reach. Community observations stay in the issue until a maintainer reproduces the result and updates the tested list. Include a link to the issue when recording a confirmed result.

For documentation or code changes, describe the observed behavior, scope and verification in the pull request. Keep game files and private logs on your machine. Preserve applicable notices and check that you have the rights to share all submitted material. The [existing license](LICENSE.en.md) describes use, modification and free distribution.

Follow the [community guidelines](CODE_OF_CONDUCT.md). For local building see the [technical guide](docs/product/guide.en.md).
