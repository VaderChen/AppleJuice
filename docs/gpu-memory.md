# GPU 記憶體設定

選取 EXE 後，到「設定 → GPU」調整「GPU 記憶體（MiB）」。Launcher 預設 4096 MiB（4 GiB），最小為 512 MiB，每格 512 MiB；上限為宿主實體記憶體的 50%，向下對齊刻度，預設值亦不超過此上限。設定按 EXE 保存，臨時執行的變更只用於本次工作階段，於下次啟動生效。

缺少或低於最小刻度的舊設定採用新預設；其餘容量向下對齊 512 MiB 並限制在系統上限內，既有有效設定保持不變。重建或替換 app 不會清除已保存的 GPU 設定。

命令列可使用 `--gpu-memory-mib 512`，同樣受宿主 50% 上限限制。CLI 預設仍為 256 MiB，並保留至少 16 MiB 的相容範圍。這是受管理圖形資源的容量上限，與客體一般記憶體上限分開，啟動時不會直接占用全部容量。

容量不足時由相應 API 回報配置失敗。診斷欄位包括 `gpu_memory_limit_bytes`、`gpu_memory_used_bytes`、`gpu_memory_peak_bytes` 與 `gpu_memory_allocations`，分別表示上限、目前保留量、峰值及成功配置次數。

Apple Silicon 使用統一記憶體；此額度不是獨立實體 VRAM，也不精確包含所有 macOS 驅動程式與圖形後端開銷。提高上限不保證程式相容或效能改善。
