# Win64 Launcher 操作

以 `./run.command` 建置並開啟 Launcher，或執行已封裝的 `build/launcher/Win64 Launcher.app`。建置方式見[建置與封裝](build-and-release.md)。

## 程式庫與執行

按「加入 EXE」加入 Windows 程式，選取後可編輯名稱、工作資料夾與命令列，再按播放圖示。文字程式使用內嵌終端，視窗程式開啟原生視窗。執行狀態、退出碼與日誌可用來排查失敗；停止圖示結束本次執行。

安裝器或一次性程式可用「臨時執行」，不必加入永久程式庫。切換臨時工作階段可查看各自狀態；停止、關閉或移除程式庫項目不應視為解除安裝客體程式。

## 設定與映射

每個 EXE 可保存自己的執行設定。確認 C 槽、其他磁碟、工作資料夾與寫入權限；應用程式附帶的 DLL 及資源須保持相對位置。需要安裝或寫入資料時，宿主目錄與本次執行都必須允許寫入。

全域設定提供語言、配色及後端選項。GPU 容量設定見[GPU 記憶體](gpu-memory.md)。設定變更通常於下次啟動程式生效，不會重設正在執行的程序。

重新建置或替換 Launcher app 會保留已保存的程式庫與個別 EXE 設定。使用 `--data-dir` 時需沿用相同資料目錄；臨時程式的設定只保留於該次 Launcher 工作階段。

32／64 位元程式預設使用 resident AOT。一般啟動預設不讀寫持久翻譯快取；「程式加速分析」可建立預編譯快取，需啟用持久快取才會載入。命令列可用 `X64ARM_AOT_PERSISTENT=1` 啟用執行期 `.smap` 快取。

## 排查問題

啟動失敗時先核對 EXE 架構、工作目錄、命令列、磁碟映射及附帶 DLL，再查看日誌。診斷可能包含檔名、路徑或程式輸出，分享前請移除個人資訊。相容性限制及 CLI 用法見[執行與相容性](realworld-support.md)。
