# Reporting a security concern

Please keep vulnerability details, exploit samples and affected users’ information private. Check the repository’s [Security tab](https://github.com/VaderChen/AppleJuice/security) for a **Report a vulnerability** button. If available, submit the affected version, impact and a minimal description privately.

If the button is unavailable, open a [minimal contact request](https://github.com/VaderChen/AppleJuice/issues/new) asking the maintainer to enable private reporting or arrange a private channel. Include only the request for contact. Wait until that channel is available before sharing details. Use the ordinary issue forms for crashes without a suspected security impact.
